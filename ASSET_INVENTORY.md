## Custom artwork now rendered

Created locally in `assets/images/art/` and `assets/images/generated/`. Sources are M-Tel's original service descriptions and the accent colours sampled from the M-Tel logo; no text, client names or claims are baked into the artwork. Animated variants add travelling dots, blinks and full-circle ripples with SMIL; reduced-motion users receive the static versions. New brand assets live in `assets/images/`. The homepage hero uses a CSS 3D flipbook of three local scene illustrations; the tiled `network-pattern.svg` is a low-opacity red page background.

## Notes

- The source site's `captcha_code_file.php` endpoint is recreated locally with a generated SVG so the contact form keeps its captcha step.
- The original banner and background files are retained but no longer rendered; their replacements are CSS patterns, so no text or imagery was altered.
- The original Font Awesome glyphs, the emoji-style benefit icons and the floating GIF icons are represented by equivalent inline SVG outlines in the design-system stroke style. Original files remain in `assets/images/` for reference, but are not rendered in the rebuilt pages.
- The heading system uses local Inter and Playfair Display WOFF2 files in `assets/fonts/`; no external font request is made at runtime.
